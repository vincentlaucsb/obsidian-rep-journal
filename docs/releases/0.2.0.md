# Rep Journal v0.2.0

- Log consecutive sets from one screen. The fields sit below the exercise name, search takes keyboard focus, and a shortcut adds 45 lb or 22.5 kg. Supersets advance to the next exercise after a save.
- Celebrate personal records at each rep count. Trophy badges in the workout log and history show which record you earned, including 1-rep and 15-rep PRs.
- Automatic session grouping starts a new workout after an hour of inactivity. Calendar choices show exercise names and available set times. Edit set identifies the date, session and set number, and Export returns to the selected workout.
- Open Progress from a workout to see that session’s chart point and history. The strength chart labels the estimated 1RM and logged set separately and uses distinct weight ticks. The Obsidian plugin embeds its renderer and the release build tests the chart offline.
- Open journals pick up arriving workout JSON files while preserving entry drafts. Rep Journal shows a warning when a connected Obsidian Sync vault excludes JSON.

For a manual update, replace `main.js`, `manifest.json`, and `styles.css` in the vault’s `.obsidian/plugins/rep-journal/` folder, then reload the plugin. Requires Obsidian 1.7.2 or later.
