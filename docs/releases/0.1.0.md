# Rep Journal v0.1.0

- Choose Metric or Imperial for your journal in Obsidian or standalone. Each exercise can inherit the journal defaults or use its own units for weight, distance, and elevation gain. Existing sets and exports retain their recorded units and precision.
- Log elevation gain in meters or feet. A recorded zero represents a flat activity. Leave the field blank when the ascent is unknown.
- Install or repair the bundled Garmin sync prompt from Rep Journal’s desktop settings. The importer can preview and fill missing elevation on existing Garmin mountain bike rides while preserving journal edits. See the [Garmin import guide](../IMPORT.md).
- Schedule workout plans by date and open them from the workout log. In Obsidian, plan instructions render as Markdown and links resolve relative to the plan note.
- The plan picker and automatic CSV refresh reuse journal data where possible. Standalone saves retry temporary Windows file-sharing errors.

For a manual update, replace `main.js`, `manifest.json`, and `styles.css` in the vault’s `.obsidian/plugins/rep-journal/` folder, then reload the plugin. The minimum supported Obsidian version is 1.7.2.
